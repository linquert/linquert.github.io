Parity in Partitions

View Problem on LeetCode ↗

A deep dive into LeetCode 3432: Visualizing the simulation, understanding parity arithmetic, and optimizing from \(O(N^2)\) to \(O(1)\).

The Question

You are given an integer array nums. A partition splits the array at index i into a Left Subarray and a Right Subarray.

We need to count how many partitions exist such that: $$ (Sum_{Left} - Sum_{Right}) \text{ is Even} $$

1. The Naive Simulation (Visualized)

The most obvious way to solve this is to physically "cut" the array at every possible spot, sum up the left side, sum up the right side, subtract them, and check the result. Why is this naive?
Notice how we recalculate the sums repeatedly. In a loop of size \(N\), calculating sum takes \(O(N)\). Total time: \(O(N^2)\).

The code for this simulation looks like this: 

class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        count = 0
        n = len(nums)
        # We check partition i from 0 to n-2
        for i in range(0, n - 1):
            left_sum = sum(nums[:i+1])
            right_sum = sum(nums[i+1:])
            
            dif = left_sum - right_sum
            
            if dif % 2 == 0:
                count = count + 1
        return count

2. Understanding Parity (The Trick)

Before we optimize, we need to understand Parity. In mathematics, parity simply means whether a number is Even or Odd.

The beauty of parity is that the actual numbers don't matter—only their "Even-ness" or "Odd-ness" matters.

Notice something? The result is Even if and only if the two numbers have the same parity.

3. The Mathematical Derivation

Let's apply the intuition from the playground to our problem. We want to know when: $$ (S_L - S_R) = \text{Even} $$

We know that the Left Sum plus the Right Sum equals the Total Sum (\(S_T\)): $$ S_L + S_R = S_T \quad \Rightarrow \quad S_R = S_T - S_L $$

Substitute \(S_R\) into our first equation: $$ S_L - (S_T - S_L) = \text{Difference} $$ $$ 2 \cdot S_L - S_T = \text{Difference} $$

The Aha! Moment

Look at the term \(2 \cdot S_L\). No matter what \(S_L\) is, multiplying it by 2 makes it Even. e.g., \(2 \times 3 = 6\) (Even), \(2 \times 4 = 8\) (Even).

So our equation is actually: $$ \text{Even} - S_T = \text{Difference} $$

Go back to the Parity Playground rules. We are subtracting \(S_T\) from an Even number.

  • If \(S_T\) is Even: We have \(Even - Even\). Result is Even.
  • If \(S_T\) is Odd: We have \(Even - Odd\). Result is Odd.

4. The Optimized Solution

The math proves that the individual partitions don't matter! The result depends entirely on the Total Sum of the array.

Conclusion:
1. If sum(nums) is Even, every possible partition has an even difference. Return \(N-1\).
2. If sum(nums) is Odd, no partition has an even difference. Return 0. 
class Solution:
    def countPartitions(self, nums: List[int]) -> int:
        n = len(nums)
        
        # We cannot partition if there are fewer than 2 elements
        if n < 2:
            return 0
            
        total = sum(nums)
        
        # O(1) Logic based on parity
        return n - 1 if total % 2 == 0 else 0

Syntax Explained

For those new to Python, here is a breakdown of the specific syntax used:

nums: List[int] -> int
This is a Type Hint. It tells developers (and IDEs) that nums is a list of integers, and the function returns an integer. Python ignores this when running the code.

sum(nums)
A built-in Python function that iterates over the list and adds all values. It runs in \(O(N)\) time.

return A if condition else B
This is a Ternary Operator (one-line if/else). In C++ or Java, this would be written as return condition ? A : B;.
