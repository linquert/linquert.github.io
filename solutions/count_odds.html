Count Odd Numbers in Range

View Problem on LeetCode ↗

A deep dive into LeetCode 1523: Why a simple loop fails, and how to use basic arithmetic to solve it in \(O(1)\).

The Question

Given two non-negative integers low and high. Return the count of odd numbers between low and high (inclusive).

Examples

Example 1: 
Input: low = 3, high = 7
Output: 3
Explanation: The odd numbers between 3 and 7 are [3, 5, 7].
Example 2: 
Input: low = 8, high = 10
Output: 1
Explanation: The odd numbers between 8 and 10 are [9].

Constraints: 0 <= low <= high <= 10^9

1. The Naive Loop (And Why It Fails)

The intuitive approach is to count them one by one. You start at low, walk up to high, and check if each number is odd. Time Complexity: \(O(N)\) where \(N\) is the difference between high and low. 

# This is too slow!
def countOdds(low, high):
    count = 0
    for i in range(low, high + 1):
        if i % 2 != 0:
            count += 1
    return count

The constraint says high can be \(10^9\) (1 billion). A simple loop will result in a Time Limit Exceeded (TLE) error. We need a mathematical approach that works instantly, or \(O(1)\).

3. The Logic & Math

We know the "distance" or total numbers covered is roughly proportional to the difference high - low.

Let's look at the math logic used in the provided solution:

Case 1: Low is EVEN & High is EVEN
e.g., Low=2, High=6 (Interval: 2, 3, 4, 5, 6)
Since the borders are even, the odds are strictly "sandwiched" inside.
$$ \text{Count} = \frac{\text{High} - \text{Low}}{2} $$
Case 2: Everything Else
e.g., Low=3, High=7 (Odd-Odd) OR Low=2, High=5 (Even-Odd)...
If at least one endpoint is Odd, integer division rounds down and misses one number. We must add 1.
$$ \text{Count} = \frac{\text{High} - \text{Low}}{2} + 1 $$

Why does `// 2` work?
Integer division by 2 calculates how many "pairs" of (Even, Odd) fit in the range. If we start or end on an Odd number, we have an "extra" incomplete pair that contains an odd number, hence the + 1.

4. The Solution Code

Here is the implementation derived from the logic above. It runs in \(O(1)\) time and \(O(1)\) space. 

class Solution:
    def countOdds(self, low: int, high: int) -> int:
        # Check if both boundaries are Even
        if low % 2 == 0 and high % 2 == 0:
            # Case 1: Even boundaries squeeze the odds
            count = (high - low) // 2
        else:
            # Case 2: At least one boundary is Odd
            # We gain an extra odd number
            count = ((high - low) // 2) + 1
            
        return count

Alternative Approach (One-Liner)

Another way to think about it is counting how many odd numbers exist from 0 to high, and subtracting how many exist from 0 to low - 1. Formula: (n + 1) // 2 gives count of odds from 0 to n. 

return (high + 1) // 2 - low // 2
